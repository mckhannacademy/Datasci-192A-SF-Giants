Group Project Repository for Data Science Practicum

Project dashboard found in parkcast_dashboard.html.

**Data Sources:**

Open Meteo API (https://open-meteo.com/)

pybaseball package (https://pypi.org/project/pybaseball/)

Baseball Savant (https://baseballsavant.mlb.com/leaderboard/statcast-park-factors)

**Structure:**

Giants Capstone (legacy inclusion): contains introductory analysis and basic linear regressions 

Stadium Photos: JPEG images used on dashboard

Data: Datasets used for analysis, includes both original versions and new versions with a day/night column attached. 

Analysis: Folders contain per-team data analysis graphics, including boxplots, heatmaps (used on dashboard), linear plots, regression outputs, distributions. Legacy versions of these plots also included (code to create these plots is in the "extra" folder). Visuals made through notebooks in the analysis folder - each notebook's role is explained in the top comment.

Final Report: Includes technical appendix, full final report, and presentation slides.

**Model:** Included in separate model branch (README found there)

**Methods:** Outlined in technical appendix/final report
